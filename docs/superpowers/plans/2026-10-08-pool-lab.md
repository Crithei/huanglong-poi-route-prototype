# 彩池演化实验室 Implementation Plan

**Goal:** 用同一片连续演化的彩池取代三个独立实验入口，观察含钙来水、蓄水、溢流和钙华积累之间的关系。

**Architecture:** `pool-lab-state.js` 提供可测试的定性水量/溶解物传递模型；`pool-lab-scene.js` 绘制固定形态的四池及剖面；`pool-lab.js` 管理时间、输入、对照和记录。通过护照桥接保存发现，不改四章3D；旧收藏与手账仍可恢复。

**Tech Stack:** 原生 JavaScript / Canvas 2D / CSS / node:test / JSDOM。

## 设计约束

- 主体始终是四个相连的彩池，几何位置不因输入或预设而重置。
- 四个相对输入：来水、溶解钙供给、CO₂逸散条件、光照。光照只影响观看效果，不伪造生化耦合。
- 定性守恒模型：输入水量与钙质依次分配至下游；溢流受水面与池沿高差影响；沉积必须有溶解物和适当逸气条件；累计池沿和池底不会随断水消失。
- 显示演示进程，不标真实流量、浓度或地质年代。水文与地貌时间都压缩，不用于现场预测。
- 暂停/继续/一步、复位、同一视角分屏对照、任意时刻留观察。未到站也可探索，正式贴纸仍需到站。
- 后台、其他页面、离开实验页与场景滚出视野时暂停，回来不补算。减少动态效果时仅通过按钮步进。
- 观察文本与已获章可送到数字手账；旧三种贴纸仍保留。
