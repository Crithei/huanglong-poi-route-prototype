# 随行四章：到站，读懂一滴水

当前版本提供水流、溶解、出露、沉积四个独立低多边形场景。打开 `?view=follow` 进入随行。原型仍为 Web 页面，正式微信小程序还需要适配 Canvas/WebGL 和定位权限。

## 怎么体验

1. 在随行顶部按游线点击“我已到达”，收下地点印章；“逛完了”才推进下一站。
2. 到达任一关联 POI，解锁对应章节。也可以在锁定章节选择“我此刻在”的景点，再点“我已到达 · 打卡解锁”补记；不自动跳过游线里的其他站。
3. 点击章节卡切换模型。未解锁时可以旋转预览，但游戏操作和奖励被锁定。
4. 点击模型上的编号，或使用下方同编号按钮、滑杆完成小游戏。模型编号会自动避让，保持 44px 点击区域。
5. 完成一章收下一枚章节印记；集齐四章获得“山水同行者”。小游戏可重玩，不重复发奖。

章节完全独立。索道上行、徒步上行或先到五彩池，都能按实际到达顺序体验。选择/删除景点、阅读详情、玩游戏不会自动产生地点打卡。

## 地点、场景与玩法

| 章节 | 任一关联地点 | 独立模型 | 小游戏 |
| --- | --- | --- | --- |
| 水流 | 金沙铺地、迎宾池 | 森林坡面、曲折水道、三段可转向水槽 | 按下坡方向连接水槽并放水；未连通处之后的水流停止 |
| 溶解 | 洗身洞观景台 | 地下岩层剖面、裂隙、三个溶解观察点 | 让水带上 CO₂，再观察三处岩石；轮廓缩小，代表溶解物的亮点进入水中 |
| 出露 | 飞瀑流辉、莲台飞瀑 | 地下含水空间、三处候选出口、地表泉流与跌水 | 选择开放裂隙，把水位推至出口线以上，触发出流 |
| 沉积 | 五彩池、争艳彩池、盆景池 | 森林彩池群、三处可增长池沿 | 逐处选择池沿，分别推动累积滑杆；三处完成后收章 |

地点绑定是科普主题关联。洗身洞观景台不代表开放入洞；地下剖面不是该地测绘资料。借飞瀑理解出露和跌水，不把它宣称为核实过的地下水源口。

出露是地下水来到地表；CO₂ 逸出是气体离开水体。含 CO₂ 的水在合适条件下可以溶解碳酸盐岩，CO₂ 逸出等变化可促使碳酸钙沉积。水滴本身不会变成石头。互动把长期过程压缩，没有声称动画秒数对应具体年限。

## 独立模型与渲染

原创程序化地景，Three.js 0.180.0（MIT），许可证在 `assets/THREE-LICENSE`。模型文件可导入 Blender 等 glTF 2.0 软件；包含完成状态的几何与材质，不含网页控制逻辑。

进入随行才创建 renderer。四章共用一个 WebGL 上下文，切换时释放旧几何与材质。场景离屏、页面进入后台时停止连续渲染，像素比最高 1.65；支持减少动态效果偏好。左右拖动旋转，上下手势保留滚动；镜头按钮与小游戏控件可用键盘操作。

不支持 WebGL 时显示章节相应的文字/二维流程，小游戏控件与解锁条件继续生效。网页打包文件约 524 KiB，无运行时 Three.js CDN 依赖。实际低端手机 GPU 性能尚未实机测量。

## 进度、奖励及原型边界

- 当前打卡是明确的手动到达记录，没有调用 GPS、后台定位、景区二维码或实物奖励兑换；不是验证到场的凭证。
- 存档仍写入 `huanglong.travel-journal.v1` 键，但内部 schema 为 version 2。v1 首次升级前备份到同名 `.backup` 键，保留原行程、印章及旧体验奖励。
- 旧“水的见证者”标记为初版纪念，不自动变成四章通关。四章奖励、完成记录和重玩进度独立。
- 读取存档时校验 POI ID、时间、选项与范围；没有关联到达依据的章节进度丢弃。锁定检查也在状态层执行，不能仅靠禁用 UI 维持规则。
- 当前浏览器/域名内自动保存，不能跨设备同步。存储不可用时显示提示；清理浏览器数据会丢失记录。
- 本站“怎么玩 / 怎么拍”仍沿用已整理的景点资料。印章册可以生成本地 PNG 纪念卡；下载是否可用取决于内嵌容器。

后续定位、二维码或景区接口可先产生经过验证的到达事件，再进入同一地点印章/解锁流程。新增现场接入不应由游戏代码直接授予地点记录；需要另行实现服务端校验及相应权限流程。

## 开发文件

- `follow-state.js`：章节与地点映射、状态机、解锁、奖励、存档迁移。
- `follow.js` / `follow.css`：旅行册、章节选择、打卡与游戏控件。
- `src/water-processes.mjs`：水流、溶解、出露三套地景，以及沉积场景适配。
- `src/water-landscape.mjs`：彩池群及逐处池沿生长。
- `src/water-scene.mjs`：renderer 生命周期、镜头、动画与模型编号。
- `src/water-pin-layout.mjs`：投影编号的避让与点击区域约束。

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run build:cloudflare

```
