# 山水护照使用与开发说明

2026-10-08。本地入口：`http://127.0.0.1:4173/?view=follow&passportTab=passport`。

## 一次完整体验

1. 随行→护照选择主题、修改名字。点主章看大图，确认“我已到达”盖章；原型不核验真实位置。
2. 去关联实验，调节滑杆、记录三种对照，收贴纸。未到站可预习，不授予收藏。
3. 手账输入标题、日期、320字短记，点已有章/贴纸/主题章加入。拖动、调整大小旋转或移除；方向键微调，Shift加快。
4. 最多12页，每页6枚。删除页需要确认，不删护照收藏。
5. 生成当前页1440px宽PNG或自包含SVG；手机长按保存。长备注自动延长页面。
6. 旅途标签保留游线进度、到达/离站与四章Three.js。顶部全部印章册保留原有章与奖励。

## 文件与状态

| 文件 | 作用 |
|---|---|
| data/passport.js | 主章、主题、实验参数与解释 |
| passport-state.js | 纯状态、校验、观察、收藏、手账边界 |
| passport.js | 界面、到达桥接、实验编辑事件、导出时序 |
| passport-art.js | 实验和手账SVG、内嵌素材、PNG导出 |
| passport.css | 手机布局、减少动画模式 |
| assets/passport/ | 6枚主章、3贴纸、3主题章 |
| scripts/build-passport-art.cjs | 重建5主章/贴纸/主题章；五彩池为手绘母版 |
| tests/passport-*.test.cjs | 状态、恢复、DOM闭环、导出竞争和素材检查 |

旧键 `huanglong.travel-journal.v1` 继续由原模块负责到达/3D进度，保留v1/v2/v3迁移。新键 `huanglong.passport.v1` 存名字、主题、观察与手账；不复制旧存档。没有账号、云同步、真实定位核验、实物兑换后台。

收藏来自已知景点有效日期。恢复时过滤未知观察/素材、异常大小、重复ID与非有限值；SVG个人文字转义。主题奖励按已满足条件计算，切主题不丢其他章。本机数据可被用户改动，不可当实物凭证。

导出前将SVG素材内嵌，避免Canvas外部依赖；编辑会使未完成的旧导出失效。预览和导出用同一SVG，选择边框不会导出。图片和矢量逐页保存。

## 启动与验证

```powershell
npm test
npm run build:cloudflare
node server.js 4173
```

新功能不需要付费API。原地图继续依赖已有高德配置。Cloudflare显式列出公开资源，文档与测试不公开部署。检查320/390/430px、实验、拖动键盘、长备注导出、无存储提示以及旧地图/3D。没有离线缓存；保存进度不等于页面可完全离线加载。

2026-10-08 验证结果：全部86项自动化测试通过（含13项新增护照测试）；Cloudflare构建通过，共40个公开文件。Edge实际浏览器完成六站打卡、三实验收集、拖动与键盘微调、PNG导出和重开恢复；320/390/430px下四个随行标签无横向溢出。测试中屏蔽外部请求，未据此确认高德线上服务的实时可用性。独立代码审查发现的边界问题已修复并复查。
