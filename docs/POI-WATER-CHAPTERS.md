# 到站解锁的水滴四章

目标：用四个独立低多边形场景承载水流、溶解、出露、沉积，游客到对应 POI 后解锁各自小游戏，任意游览顺序均可完成。

本轮延续用户已经授权的原型迭代，直接在实验分支实现。保留现有地图、POI、路线、攻略和印章。

## 场景与互动

| 章节 | 关联地点，任一到达即可 | 场景 | 完成条件 |
| --- | --- | --- | --- |
| 水流 | 金沙铺地、迎宾池 | 森林坡面、曲折水道、可转向的三段水槽 | 调整三段方向，使水路连通后放水 |
| 溶解 | 洗身洞观景台 | 带地表树木的地下岩层剖面、裂隙与溶解点 | 加入含 CO2 的水，再观察三个溶解点 |
| 出露 | 飞瀑流辉、莲台飞瀑 | 岩层剖面连接泉口、跌水和溪流 | 选择连通地表的出口，提升水位至出口高度后观察出流 |
| 沉积 | 五彩池、争艳彩池、盆景池 | 原有彩池微缩景观，三处可生长池沿 | 逐处选择池沿并推演长期水流，三处沉积均完成 |

映射为科普主题关联，洗身洞不意味着开放入洞，飞瀑不是已核实地下水源口。文案明确地下结构为解释模型；出露与二氧化碳逸出是不同过程。水中溶解物在合适条件下沉积，水本身不会变成石头；动画无真实时间比例。

## 状态及界面

- 2×2 章节卡展示关联 POI、锁定/已解锁/已完成。选中锁定章节可看模型预览，互动禁用。
- 沿用手动到达；章节锁定面板提供明确的地点选择与“我已到达”按钮。该补记只写地点印章，不跳过计划中的站点。
- 到达事件与地点印章为解锁依据，路线选择、景点详情查看或游戏本身均不产生到达记录。
- 不要求先完成前章；删改路线不清除已有解锁。游戏可重玩，奖励只发一次。
- 新四章奖励与旧“一滴水”纪念章独立，旧用户章保留，不能迁移成四章通关。
- v1 存档迁移到 v2，保留选点、偏好、到达、印章和旧奖励；校验新进度及地点依据。继续使用原 localStorage 键以便自动升级，另保留 v1 原始快照便于回退。
- 单个 renderer 按需切换模型并释放前一个场景；动画离屏停止。手势旋转与按钮均可用。无 WebGL 时提供对应章节文字及二维流程，小游戏仍可操作。

## 回退

本轮前版本：`archive/2026-09-20-before-poi-chapters`，提交 `02204d1`；本轮分支 `feature/poi-water-chapters`。

恢复原单场景版本：

```powershell
git worktree add ../huanglong-single-scene-restore archive/2026-09-20-before-poi-chapters
Set-Location ../huanglong-single-scene-restore
npm.cmd ci
npm.cmd run deploy:cloudflare
```

旧版本只接受 v1 存档。回退页面后，在浏览器开发工具执行下句可恢复本轮升级前的旅行记录（会替换当前记录）：

```js
const saved = localStorage.getItem('huanglong.travel-journal.v1.backup');
if (saved) localStorage.setItem('huanglong.travel-journal.v1', saved);
```
