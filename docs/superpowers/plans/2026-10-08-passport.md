# 黄龙山水护照 Implementation Plan

**Goal:** 在现有随行和四章 Three.js 体验上增加可完整使用的数字护照、观察实验、原创章和数字手账，并交付实体联动策划。

**Architecture:** 原随行存档仍负责真实操作中的手动到达记录与四章奖励；独立 `passport-state.js` 负责实验记录、主题、手账，通过 `HuanglongFollow` 的桥接读取到达并打卡。使用单独存储键，保护旧版 v1/v2/v3 迁移。所有实物联动只进入策划，不发放真实兑换权益。

**Tech Stack:** 原生 HTML/CSS/JS、SVG、Canvas PNG 导出、Node test/JSDOM、Playwright 本地预览。

## 产品与验收

- [x] 护照：六枚主章、更多景点旧章继续可用；先确认到达才盖章；同一景点不重复计数；路线可逆序、可缩短；三种主题分别按任意两站、三站、两站加一次实验获得数字纪念；完整规则可随时查看。
- [x] 实验：水色实验（水深/清澈程度）、薄水与地形（坡度/供水）、留下一层石（CO₂ 交换/时间）。每个实验记录三个对照状态才解锁一次贴纸，预习不会授予到达或正式收集。明确简化机制和非测量刻度。记录后提供因果解释和现场观察建议。
- [x] 美术：六枚 SVG（五彩池、迎宾池、飞瀑流辉、金沙铺地、盆景池、争艳彩池），各有不同的景观结构，使用同系列纸白、深绿、矿物色与暖金边框。显示大图、放大细节、灰度未获得态。
- [x] 手账：多页、标题、日期、短记、纸色；仅可放入已拥有的章/贴纸；支持拖动、键盘微调、大小、旋转、移除；重开恢复；PNG 与 SVG 导出实际编辑画面；无章时空白手账也能保存。
- [x] 集成：随行顶部分为旅途/护照/实验/手账；3D 原体验完整保留。320/390/430px 无横向溢出，触控不低于44px，减少动画模式可用。
- [x] 策划：完整收集规则、三种有机制特色的文创、设计图案来源与生产要求、低成本试点、核销/库存/异常、预算假设与成效指标、正式上线前的验证项。

## 实现顺序与文件

1. `tests/passport-state.test.cjs`：锁定/预习/重复/恢复/输入边界/三实验/手账拥有权；运行 `node --test tests/passport-state.test.cjs` 观察新功能缺失。
2. `data/passport.js`：地点、实验、目标、科学解释和主题。`passport-state.js`：纯函数 API `create, restore, sample, experimentView, inventory, milestones, addPage, updatePage, addItem, moveItem, removeItem`，验证所有边界。
3. `scripts/build-passport-art.cjs` 与 `assets/passport/*.svg`：确定性原创章和贴纸；六枚章均检查大图及小图效果。
4. `passport.js, passport.css`：界面、交互、导出，桥接 `follow.js`；在 `index.html` 加载，`scripts/build-cloudflare.cjs` 明确列入新文件。
5. `tests/passport-page.test.cjs`：从到达、实验收集到手账编排的真实 DOM 链路；模拟禁用存储时明确提示。全部旧测试通过。
6. `docs/黄龙山水护照与实体纪念品联动策划.md`：完整策划。`docs/passport-guide.md`：运行、交互、数据/科普边界与回退说明。
7. 执行 `npm test`、`npm run build:cloudflare`，移动端浏览器实际验证、独立代码审查、修复发现的问题。
8. Git 独立存档并展示本地预览。线上继续沿用 Workers 部署路径。
