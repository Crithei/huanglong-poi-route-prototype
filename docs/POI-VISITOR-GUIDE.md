# POI 游客导览优化 · 2026-09-20

## 问题与设计

已有 14 个景点的长介绍和资料链接，但资料说明与游客建议混在首屏，多个彩池的区别不够容易浏览。此次维持方形卡片和手机竖屏布局，调整内容层次，帮助游客从“知道名称”走到“决定是否加入”。

卡片显示一句独特看点与“停留约 N 分钟”；详情依次为导读、所在区域与参考停留、三个看点、观看与取舍建议、可展开的景观故事、游览提醒、摄影建议、来源、地图定位说明。两列/三列容器断点、POI 标识、坐标、游线权重和分钟值沿用现有数据。

## 与游客研究的关系

依据本地 `huanglong-persona-research-20260920` 中的质性研究，把多种游览偏好用于编辑建议，不把研究样本比例当成游客总体比例。

| 研究线索 | 本次落点 |
| --- | --- |
| X02、M02：剩余步行与攻略预期有差异 | 停留明确不含到达、换观景位置与返程；不把景点轻松看误写为全程轻松 |
| Z02：抵达附近未必到达想看的视角 | 五彩池明确休息亭参考点、现场观景位置与换位置时间 |
| X03、X05：索道省力与沿线慢看是不同偏好 | 景点取舍结合想看什么，不把少走路设为所有人的目标 |
| C02、C05、Z02：雪景、水量与季节预期不同 | 彩池颜色、倒影和花期作为变化条件，不承诺固定效果 |
| X09：同行者节奏可能不同 | 洗身洞观景台加入交流节奏的建议，不用年龄推断体力 |

研究材料用于发现决策问题；景点位置与景观背景继续依据每条 POI 所列官方/地图资料。用户评论没有转写成景区官方规则。

## 内容与事实边界

- `visitGuide.viewing`：从允许通行位置怎样看，不能虚构观景台、入口或精确距离。
- `visitGuide.tradeoff`：不同兴趣与剩余时间下的编辑建议，不保证任何组合当天都可通行。
- `visitGuide.expectation`：季节、光线、水量、开放条件对体验的影响。
- `checkedAt` 保留 2026-09-18 的资料核对日期；`editorialUpdatedAt` 为 2026-09-20。本轮重编已有可核对资料，没有把文案修改伪装为新一轮实地/官网开放核验。
- 所有景点保留两段以上故事与来源；莲台飞瀑、洗身洞观景台不补写未核实的尺度或典故。
- 黄龙洞的参考停留仅用于允许到达的周边/洞口；洗身洞观景台不是入洞入口。
- 参考坐标说明靠近定位按钮，保留附近设施或休息亭的实际含义。
- 设施详情继续显示地点资料与步行操作，不展示景点故事/取舍面板。
