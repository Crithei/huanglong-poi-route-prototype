# 水滴连续过程交互

用户已明确四章交互，直接迭代。回退标签 `archive/2026-09-20-before-fluid-scenes`（`7c289b6`），分支 `feature/fluid-water-story`。

- 水流：不断流动的源水，三个可点击转向的实体水槽；接通后持续径流/渗入地下含水层。转向插值过渡，不显示编号徽标。
- 溶解：把 CO₂ 拖到水滴上，显示“让水带上 CO₂”。鼠标/触控用 Pointer Events；键盘提供同等加入操作。随后自动播放水流、三段岩石缩小及溶解粒子，无需点击观察点。
- 出露：山体及地质剖面，单一水位滑杆；达到出口高度后连续显示渗出、溪流和 CO₂ 逸出。删除出口选择。
- 沉积：上方三池保留，下方三池初始不存在。每次启动一轮，自动播放池沿生长（3s）、蓄水（3s）、溢流（2.5s），停在下一新池生成前，三轮完成收章。

过程时长均为演示节奏，不对应真实年限。粒子表示水流/溶解物/气体，不把岩石碎块当作溶解物。

## 状态契约

schema version 3；保留旧键，备份 v2。迁移保留地点、已获奖励、可兼容的水槽方向与水位；旧溶解/沉积未完成操作重置，不凭旧点击伪造新过程。

`flow {channels,runoff}`；`dissolution {charged,elapsed}`；`emergence {level,exposure}`；`deposition {sequence,fraction,running}`。所有章节继续带 `won,earnedAt`。

`tickChapter(state,id,dt)` 只推进已解锁的当前章节；每次 dt 限制 0.25s，隐藏/暂停/切章不追赶时间。水流接通并观测 4s、溶解观测 8s、出露观测 4s、三池全部完成时自动收章。重复播放不重复发奖。

模型接口 `update(time,progress,delta,snap)`；单 renderer、按需释放，动态效果可暂停。减少动态效果时不播放粒子，用明确的“查看下一状态”逐步体验。
